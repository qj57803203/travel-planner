🔐 小红书登录配置

旅行规划 Agent 需要小红书登录态来搜索攻略笔记。Cookie 有效期约 7-30 天，过期后需重新获取。

📱 扫码登录（推荐）

💡 检测到小红书需要登录，请用手机 App 扫描下方二维码完成登录

1. 打开小红书 App

2. 点击右上角「+」→「扫一扫」

3. 扫描上方二维码

方式一：浏览器导出
方式二：虚拟桌面登录

从浏览器导出 Cookie

1
在本地浏览器登录小红书
访问 www.xiaohongshu.com 并完成登录
2
打开开发者工具（F12）→ Network 标签
刷新页面，在请求列表中点击任意一个请求
3
复制 Cookie 请求头
在 Request Headers 中找到 Cookie 行，右键复制完整值
4
粘贴到下方并提交
支持格式：分号分隔的 key=value 字符串，或 JSON 数组格式

通过虚拟桌面登录

1
启动登录浏览器容器
在服务器执行：
cd ~/travel-planner/deploy
docker compose --profile login up -d xhs-browser
2
访问虚拟桌面
浏览器打开 http://服务器IP:6080，输入密码 xhs123
3
在虚拟桌面中登录小红书
打开桌面的 Firefox 浏览器，访问 xiaohongshu.com 并登录
4
运行登录脚本导出 Cookie
在虚拟桌面中打开终端（桌面右键 → Open Terminal），执行：
python3 /app/xhs_login.py
脚本会自动提取浏览器 Cookie 并保存
💡 虚拟桌面方式适合首次配置，后续 Cookie 过期可用方式一快速更新

提交 Cookie

将从浏览器复制的 Cookie 粘贴到上方输入框，点击保存。

ℹ️ 说明

  • Cookie 保存后立即生效，无需重启服务
  • 有效期约 7-30 天，搜索返回空结果时说明已过期
  • Cookie 仅存储在服务器本地，不会上传到第三方
  • 关键 Cookie 字段：web_session、a1、webId
