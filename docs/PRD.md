# PRD：个人旅行规划agent助手

## 1. 产品定位

面向个人自用的旅行规划工具。

用户输入一句旅行需求，系统自动搜集整理酒店、攻略、美食、交通等信息，并生成一份每日行程。用户不需要自己翻遍各种攻略。

---

## 2. 产品目标

让用户「输入需求 → 拿到一份可用的旅行计划」。

MVP 只验证一件事：**能自动把散落的信息汇总起来，并生成一份像样的行程。**

---

## 3. 用户使用流程

```text
1. 用户打开页面，输入旅行需求（如"9 月去东京玩 5 天，不想太累"）
2. 系统抽取目的地、天数、偏好
3. 系统自动搜集整理信息：酒店候选、攻略要点、美食、交通
4. 系统生成每日行程
5. 用户查看结果，保存或重新生成
```

## 5. 核心功能

### 5.1 需求输入与偏好抽取

用户输入自然语言需求。

示例：

```text
我 9 月去东京玩 5 天，喜欢美食和拍照，不想太累，酒店希望靠近地铁。
```

系统抽取为结构化偏好：

```json
{
  "destination": "东京",
  "days": 5,
  "pace": "轻松",
  "interests": ["美食", "拍照"],
  "hotel_preference": ["靠近地铁"]
}
```

### 5.2 信息汇总

系统自动搜集并整理四类信息，合并为一份旅行资料：

```text
酒店候选：名称、价格、评分、位置、优缺点
攻略要点：必去景点、推荐路线、避坑点
美食：推荐餐厅、热门美食
交通：市内交通方式、常用路线
```

### 5.3 行程生成

根据目的地、天数、偏好和信息汇总，生成每日行程。

生成原则：

```text
同一天安排相近区域，避免来回横跨
"轻松"模式下减少景点数量
热门景点安排在合适时间段
晚上优先安排商圈、美食、夜景
保留休息时间
```

输出示例：

```text
Day 1：抵达 + 新宿周边
上午：抵达东京，前往酒店寄存行李
下午：新宿御苑、新宿站周边
晚上：歌舞伎町、思出横丁晚餐

Day 2：涩谷 + 原宿
上午：涩谷 Sky、忠犬八公
下午：原宿竹下通
晚上：涩谷周边晚餐和购物
```

## 6. 页面设计

单页即可，三段式布局：

```text
左侧：旅行需求输入区
右侧：行程结果 + 搜集到的信息素材
底部：生成行程 / 重新生成 / 保存
```

---

## 7. 验收标准

```text
能根据一句需求抽取目的地、天数、偏好
能自动汇总酒店、攻略、美食、交通四类信息
能生成按天划分的每日行程
行程能体现用户偏好（如"轻松"则景点较少）
结果可保存
```

## 8. 后续规划

### ✅ 第一阶段（MVP 已完成）

核心链路跑通：输入需求 → 抽取偏好 → 搜集信息 → 生成行程 → 保存结果。

已实现：
- **偏好抽取**：LLM 从自然语言提取目的地、天数、节奏、兴趣、酒店偏好、出发地
- **信息汇总**：预置目的地结构化数据（酒店/景点/美食/交通）兜底
- **行程生成**：LLM 按天生成行程（含上/下午/晚三段），支持轻松/适中/紧凑三种节奏
- **行程保存**：SQLite 持久化，支持历史列表 + 详情查看
- **前端页面**：Vue 3 + Element Plus，三段式布局（输入 | 结果 | 底部操作）

### ✅ 第二阶段（已完成）

数据源扩展 + 真实交通规划 + 体验优化。

已实现：
- **小红书攻略接入**：MCP 协议实时爬取小红书笔记，一周缓存，失败不阻塞主流程
- **高德地图交通规划**：
  - 城际交通：驾车 / 高铁 / 飞机三种方式，LLM 根据距离自动推荐
  - 市内交通：逐天逐段规划，<2km 步行，≥2km 对比驾车和地铁选耗时短的
  - 路线注入行程：交通信息穿插在景点之间（emoji 标注步行/地铁/驾车）
- **地图路线可视化**：高德 JS API 绘制路线，按天分色、Day 标签、景点圆点颜色跟随路线
- **流式生成**：SSE 流式推送，实时显示小红书采集进度
- **Token 用量统计**：各 LLM 节点的 input/output token 独立统计
- **用户出发地记忆**：记住用户常用出发地，无需每次输入
- **诊断日志体系**：后端交通规划全链路日志 + 前端地图渲染诊断（坐标/polyline 异常检测）

### 🔜 第三阶段（规划中）

多轮交互 + 个性化。

```text
多轮修改：用户说"太累了""酒店换便宜点"，系统理解反馈并重新规划
会话记忆：记住上下文，支持追问（"第二天下午还有什么推荐？"）
酒店横向对比：同目的地酒店按价格/评分/位置排序推荐
预算估算：根据交通/住宿/餐饮自动估算总费用
```
