# 高德地图路线可视化方案

## Context

当前交通信息只是纯文本注入到行程 markdown 中，无法直观看到路线。用户希望在地图上可视化多天路线，用不同颜色区分每天，并标记天数。

**好消息**：后端 transit 数据已经包含完整的经纬度坐标（from/to 的 lng/lat 和 polyline 路线点），前端 TS 类型也已定义好，只需要前端集成高德地图 JS API 即可。

---

## 实现方案

### 1. 前端引入高德地图 JS API

在 `index.html` 中引入高德地图 JS API 2.0：

```html
<script src="https://webapi.amap.com/maps?v=2.0&key=你的高德Key"></script>
```

### 2. 新建地图组件 `MapRoute.vue`

路径：`frontend/src/components/MapRoute.vue`

功能：
- 使用高德地图 JS API 渲染地图
- 根据 transit 数据绘制路线（Polyline）
- 每天用不同颜色（预设 7 种颜色循环）
- 在每个景点位置添加 Marker，标注天数和序号
- 自动调整地图视野以包含所有路线

颜色方案（每天一种）：
```
Day 1: #FF0000 (红)
Day 2: #0000FF (蓝)
Day 3: #00AA00 (绿)
Day 4: #FF8C00 (橙)
Day 5: #800080 (紫)
Day 6: #00CED1 (青)
Day 7: #FFD700 (金)
```

Marker 样式：
- 使用高德 Marker + 自定义 Content
- 显示 "D1-1"（第1天第1个点）格式的标签

### 3. 在 ItineraryView.vue 中添加「地图」Tab

当前有两个 Tab：每日行程 / 信息素材。新增第三个 Tab「路线地图」。

```vue
<el-tabs v-model="activeTab">
  <el-tab-pane label="每日行程" name="itinerary">...</el-tab-pane>
  <el-tab-pane label="信息素材" name="research">...</el-tab-pane>
  <el-tab-pane label="路线地图" name="map">  <!-- 新增 -->
    <MapRoute :transit="trip.transit" :itinerary="trip.itinerary" />
  </el-tab-pane>
</el-tabs>
```

### 4. 城际交通处理

如果存在 inter_city（城际交通），也用特殊颜色（灰色虚线）绘制在地图上。

## 修改文件清单

| 文件 | 改动 |
|------|------|
| `frontend/index.html` | 引入高德地图 JS API 脚本 |
| `frontend/src/components/MapRoute.vue` | **新建**，地图路线组件 |
| `frontend/src/components/ItineraryView.vue` | 添加「路线地图」Tab，引入 MapRoute |
| `frontend/src/env.d.ts` | 添加高德地图类型声明（可选） |

---

## 验证方式

1. 启动前端 `npm run dev`
2. 生成一个包含多天行程的旅行计划
3. 查看「路线地图」Tab，确认：
   - 地图正常显示
   - 每天路线用不同颜色绘制
   - 景点 Marker 正确标注天数和序号
   - 地图视野自动适配
