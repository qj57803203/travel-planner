# Docker 部署

服务器 IP：`118.89.71.196`，SSH 用户：`ubuntu`

## 架构说明

```
用户访问 http://118.89.71.196/
    ↓
Nginx (前端容器，端口 80)
    ↓ 反向代理 /api
FastAPI (后端容器，端口 8000)
    ↓ 内部调用
┌─────────────────────────────────────────────────────┐
│  PostgreSQL (宿主机，端口 5432)                       │  ← 数据库
│  Chrome (内部端口 9223)                              │  ← 携程酒店爬虫共用
│  xiaohongshu-mcp (内部端口 18060)                    │  ← 小红书主力方案（MCP 协议）
│  高德地图 API (外部 HTTP)                            │
└─────────────────────────────────────────────────────┘
```

### 服务组件

| 组件 | 位置 | 端口 | 内存占用 | 说明 |
|------|------|------|---------|------|
| PostgreSQL | 宿主机 | 5432 | ~100 MiB | 数据库（监听 localhost，Docker 通过 host.docker.internal 访问） |
| Nginx | travel-frontend | 80 | ~3 MiB | 托管前端，反向代理 API |
| FastAPI | travel-backend | 8000 | ~183 MiB | 后端 API + LangGraph Agent |
| Chrome | travel-chrome | 内部 9223 | ~223 MiB | 携程酒店爬虫共用（小红书已迁移到 MCP） |
| 小红书 MCP | xiaohongshu-mcp | 内部 18060 | ~362 MiB | 小红书主力方案（搜索/详情/登录） |

**总内存占用**：~871 MiB / 1.92 GiB（约 45%）

## 第一步：上传代码

```bash
# 本地打包上传（排除 .git 等）
cd d:/项目/旅游攻略
git archive --format=tar.gz -o /tmp/travel-planner.tar.gz
scp /tmp/travel-planner.tar.gz ubuntu@118.89.71.196:~/

# 服务器解压
ssh ubuntu@118.89.71.196 "mkdir -p ~/travel-planner && tar -xzf ~/travel-planner.tar.gz -C ~/travel-planner"
```

## 第二步：配置环境变量

```bash
# 创建 backend.env
cat > ~/travel-planner/deploy/backend.env << 'EOF'
DEEPSEEK_API_KEY=sk-你的key
DEEPSEEK_MODEL=deepseek-chat
DATABASE_URL=postgresql://travel:travel2026@host.docker.internal:5432/travel_planner
AMAP_WEB_KEY=你的高德key
AMAP_TIMEOUT_S=15
# Chrome（小红书 + 携程共用，Playwright CDP 直连）
CHROME_DEBUG_URL=http://chrome:9222
REMOTE_BROWSER=1
CTRIPE_CACHE_TTL_DAYS=7
# 小红书 MCP（可选 fallback，默认不启用）
# XHS_MCP_URL=http://xiaohongshu-mcp:18060/mcp
EOF
```

### 外部服务配置说明

| 服务 | 环境变量 | 说明 |
|------|----------|------|
| 高德地图 | `AMAP_WEB_KEY` | https://lbs.amap.com 注册，创建「Web 服务」应用 |
| Chrome | `CHROME_DEBUG_URL` | Docker 内 headless Chrome，CDP 直连主方案（222 MiB） |
| 小红书 MCP | `XHS_MCP_URL` | MCP fallback，CDP 失败时自动降级（361 MiB） |

**降级策略**：CDP 直连方案优先，失败时自动降级到 MCP 容器方案。两个方案都失败时，使用预置数据兜底。

## 第三步：安装 PostgreSQL（宿主机）

```bash
# 安装 PostgreSQL 16
sudo apt update
sudo apt install -y postgresql postgresql-contrib

# 启动服务并设置开机自启
sudo systemctl start postgresql
sudo systemctl enable postgresql

# 创建用户和数据库
sudo -u postgres psql -c "CREATE USER travel WITH PASSWORD 'travel2026';"
sudo -u postgres psql -c "CREATE DATABASE travel_planner OWNER travel;"

# 配置允许 Docker 网络访问（宿主机安装时需要）
# 修改监听地址
sudo sed -i "s/#listen_addresses = 'localhost'/listen_addresses = '*'/" /etc/postgresql/16/main/postgresql.conf

# 添加 Docker 网段到 pg_hba.conf
echo 'host    all             all             172.16.0.0/12           scram-sha-256' | sudo tee -a /etc/postgresql/16/main/pg_hba.conf

# 重启 PostgreSQL 使配置生效
sudo systemctl restart postgresql

# 验证连接
PGPASSWORD=travel2026 psql -U travel -h localhost -d travel_planner -c "SELECT version();"
```

## 第四步：启动服务

```bash
cd ~/travel-planner/deploy

# 首次启动（会自动拉取镜像，约 2GB）
sudo docker compose up -d
```

## 小红书登录配置

小红书攻略采集需要登录态（cookies），通过 MCP 二维码扫码登录：

### 登录方式：MCP 二维码扫码（推荐）

1. 访问 http://118.89.71.196/xhs-login.html
2. 点击「获取登录二维码」按钮
3. 等待 10-20 秒（MCP 服务启动浏览器获取二维码）
4. 用手机小红书 App 扫描二维码
5. 登录成功后 Cookie 自动保存到 `/app/data/cookies.json`

### Cookies 有效期

- 有效期：7-30 天
- 过期表现：搜索返回空结果
- 处理方式：重新扫码登录
