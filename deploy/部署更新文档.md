# Docker 部署

服务器 IP：`118.89.71.196`，SSH 用户：`ubuntu`

## 架构说明

```
用户访问 http://118.89.71.196/
    ↓
Nginx (前端容器，端口 80)
    ↓ 反向代理 /api
FastAPI (后端容器，端口 8000)
    ↓ 内部调用
┌─────────────────────────────────────┐
│  Chrome (内部端口 9222)             │  ← 小红书 + 携程共用
│  Playwright CDP 直连（无 MCP 中间层）│
│  高德地图 API (外部 HTTP)           │
└─────────────────────────────────────┘
```

### 服务组件

| 组件 | 容器名 | 端口 | 说明 |
|------|--------|------|------|
| Nginx | travel-frontend | 80 | 托管前端，反向代理 API |
| FastAPI | travel-backend | 8000 | 后端 API + LangGraph Agent |
| Chrome | travel-chrome | 内部 9222 | 小红书 + 携程共用（Playwright CDP 直连） |
| 小红书 MCP | xiaohongshu-mcp | 内部 18060 | **可选** fallback（默认不启动） |

## 第一步：上传代码

```bash
# 本地打包上传（排除 .git 等）
cd d:/项目/旅游攻略
git archive --format=tar.gz -o /tmp/travel-planner.tar.gz
scp /tmp/travel-planner.tar.gz ubuntu@118.89.71.196:~/

# 服务器解压
ssh ubuntu@118.89.71.196 "mkdir -p ~/travel-planner && tar -xzf ~/travel-planner.tar.gz -C ~/travel-planner"
```

## 第二步：配置环境变量

```bash
# 创建 backend.env
cat > ~/travel-planner/deploy/backend.env << 'EOF'
DEEPSEEK_API_KEY=sk-你的key
DEEPSEEK_MODEL=deepseek-chat
DATABASE_URL=sqlite:///./trips.db
AMAP_WEB_KEY=你的高德key
AMAP_TIMEOUT_S=15
# Chrome（小红书 + 携程共用，Playwright CDP 直连）
CHROME_DEBUG_URL=http://chrome:9222
REMOTE_BROWSER=1
CTRIPE_CACHE_TTL_DAYS=7
# 小红书 MCP（可选 fallback，默认不启用）
# XHS_MCP_URL=http://xiaohongshu-mcp:18060/mcp
EOF
```

### 外部服务配置说明

| 服务 | 环境变量 | 说明 |
|------|----------|------|
| 高德地图 | `AMAP_WEB_KEY` | https://lbs.amap.com 注册，创建「Web 服务」应用 |
| Chrome | `CHROME_DEBUG_URL` | Docker 内 headless Chrome，小红书 + 携程共用 |
| 小红书 MCP | `XHS_MCP_URL` | **可选** fallback，需要时取消注释并启动 `--profile mcp` |

## 第三步：创建数据文件

```bash
# 创建数据目录和 SQLite 文件（必须先创建，否则容器挂载失败）
sudo mkdir -p ~/travel-planner/deploy/data
sudo touch ~/travel-planner/deploy/data/trips.db
sudo chmod 666 ~/travel-planner/deploy/data/trips.db
```

## 第四步：启动服务

```bash
cd ~/travel-planner/deploy

# 首次启动（会自动拉取镜像，约 2GB）
sudo docker compose up -d

# 检查状态
sudo docker ps
```

## 第五步：验证

```bash
# 健康检查
curl http://118.89.71.196/health

# 浏览器访问
# http://118.89.71.196
```

## 常用命令

```bash
# 本地连接远程
ssh ubuntu@118.89.71.196

# 查看所有容器状态
sudo docker ps

# 查看后端日志
sudo docker logs travel-backend -f

# 查看前端日志
sudo docker logs travel-frontend -f

# 重启所有服务
cd ~/travel-planner/deploy
sudo docker compose restart

# 重启单个服务
sudo docker compose restart backend

# 停止所有服务
sudo docker compose down

# 重新构建并启动（代码更新后）
sudo docker compose up -d --build
```

## 小红书登录配置

小红书攻略采集需要登录态（cookies），有两种配置方式：

### 方式一：在线上传页面（推荐）

1. 访问 http://118.89.71.196/xhs-login.html
2. 按页面提示操作：
   - 在本地浏览器登录小红书
   - 安装 Cookie-Editor 或 EditThisCookie 插件
   - 导出 cookies 并粘贴到页面
3. 点击"保存 Cookies"，系统会自动保存并重启小红书 MCP 服务

### 方式二：虚拟桌面登录

1. 访问 http://118.89.71.196:6080（密码：xhs123）
2. 在虚拟桌面中打开浏览器，登录小红书
3. 导出 cookies 保存到 `/app/data/cookies.json`

### Cookies 有效期

- 有效期：7-30 天
- 过期表现：搜索返回空结果
- 处理方式：重新获取 cookies
