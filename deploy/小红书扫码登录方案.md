# 小红书扫码登录方案

> 创建：2026-09-06　状态：已实现

## 背景 / 需求

小红书爬虫需要登录态才能搜索攻略笔记。之前的方案需要用户手动复制 Cookie，体验不好。

**新方案**：截图直播 + 手机扫码登录

- 服务器 Chrome 遇到登录墙时，Agent 暂停
- 前端实时展示登录页截图（二维码），用户用手机 App 扫码
- 登录成功后，Agent 自动继续抓取

## 方案设计

### 核心流程

```
1. 用户发起行程生成 → 小红书爬虫访问搜索页
2. 检测到登录墙 → 进入等待模式
3. 后端每 3 秒截图一次，保存到全局变量
4. 前端 /xhs-login.html 页面轮询检测登录状态
5. 检测到 waiting=true → 显示扫码区域，每 3 秒刷新截图
6. 用户用手机 App 扫码登录
7. 后端检测到搜索结果出现 → 登录成功
8. 清除等待状态，继续抓取笔记
```

### 关键组件

| 组件 | 文件 | 功能 |
|---|---|---|
| 截图方法 | `backend/app/tools/chrome_manager.py` | `CDPPage.screenshot()` 方法 |
| 登录等待 | `backend/app/tools/xhs_browser.py` | `_wait_for_xhs_login()` 轮询循环 |

| 状态 API | `backend/app/routers/trips.py` | `GET /api/xhs-login-status` |
| 前端页面 | `frontend/public/xhs-login.html` | 扫码区域 + 截图轮询 |

### 代码改动

#### 1. chrome_manager.py - 添加截图方法

```python
async def screenshot(self, path: str = None, quality: int = 60) -> str:
    """截图并返回 base64 编码的图片数据。"""
    result = await self._send("Page.captureScreenshot", {
        "format": "jpeg",
        "quality": quality,
    })
    import base64
    data = result.get("data", "")
    if path and data:
        with open(path, "wb") as f:
            f.write(base64.b64decode(data))
    return data
```

#### 2. xhs_browser.py - 登录等待函数

```python
async def _wait_for_xhs_login(page, search_url: str) -> bool:
    """等待用户完成小红书登录（截图直播 + 手机扫码）。"""
    from app.routers.trips import _xhs_login_screenshot, _xhs_login_waiting
    import app.routers.trips as trips_module

    trips_module._xhs_login_waiting = True
    trips_module._xhs_login_screenshot = ""

    try:
        # 先截一帧，避免前端第一次拉图 404
        screenshot_data = await page.screenshot(quality=60)
        trips_module._xhs_login_screenshot = screenshot_data

        waited = 0.0
        while waited < _LOGIN_WAIT_TIMEOUT:
            await asyncio.sleep(_LOGIN_POLL_INTERVAL)
            waited += _LOGIN_POLL_INTERVAL

            # 刷新截图
            screenshot_data = await page.screenshot(quality=60)
            trips_module._xhs_login_screenshot = screenshot_data

            # 检测页面是否已登录
            feed_items = await page.query_selector_all('[class*="note-item"]')
            if feed_items:
                return True

        return False
    finally:
        trips_module._xhs_login_waiting = False
        trips_module._xhs_login_screenshot = ""
```

#### 3. trips.py - 截图 API 端点

```python
_xhs_login_screenshot: str = ""
_xhs_login_waiting: bool = False

@router.get("/xhs-login-screenshot")
def get_xhs_login_screenshot():
    """获取小红书登录页的实时截图（前端轮询用）。"""
    from fastapi.responses import Response
    import base64

    if not _xhs_login_waiting or not _xhs_login_screenshot:
        raise HTTPException(status_code=404, detail="当前未在等待登录")

    image_data = base64.b64decode(_xhs_login_screenshot)
    return Response(content=image_data, media_type="image/jpeg")

@router.get("/xhs-login-status")
def get_xhs_login_status():
    """查询小红书登录等待状态。"""
    return {
        "waiting": _xhs_login_waiting,
        "has_screenshot": bool(_xhs_login_screenshot),
    }
```

#### 4. xhs-login.html - 前端轮询

```html
<!-- 实时扫码登录区域 -->
<div id="scan-login-section" style="display: none;">
  <h2>📱 扫码登录（推荐）</h2>
  <img id="login-screenshot" src="" alt="登录页截图">
  <p>1. 打开小红书 App</p>
  <p>2. 点击右上角「+」→「扫一扫」</p>
  <p>3. 扫描上方二维码</p>
</div>

<script>
// 每 5 秒检查登录状态
setInterval(checkLoginStatus, 5000);

async function checkLoginStatus() {
  const resp = await fetch('/api/xhs-login-status');
  const data = await resp.json();

  if (data.waiting) {
    document.getElementById('scan-login-section').style.display = 'block';
    setInterval(refreshScreenshot, 3000);
  }
}

async function refreshScreenshot() {
  const img = document.getElementById('login-screenshot');
  img.src = '/api/xhs-login-screenshot?t=' + new Date().getTime();
}
</script>
```

## 使用流程

### 用户视角

1. 用户访问 `/xhs-login.html` 页面
2. 如果小红书需要登录，页面会自动显示扫码区域
3. 用户用手机小红书 App 扫描二维码
4. 登录成功后，页面自动隐藏扫码区域

### 技术视角

1. 用户发起行程生成
2. 小红书爬虫访问搜索页
3. 检测到登录墙 → 设置 `_xhs_login_waiting = True`
4. 进入轮询循环，每 3 秒：
   - 截图并保存到 `_xhs_login_screenshot`
   - 检测页面是否出现搜索结果
5. 前端轮询 `/api/xhs-login-status`
6. 检测到 `waiting=true` → 显示扫码区域
7. 前端每 3 秒刷新 `/api/xhs-login-screenshot`
8. 用户扫码登录
9. 后端检测到搜索结果 → 设置 `_xhs_login_waiting = False`
10. 前端检测到 `waiting=false` → 隐藏扫码区域
11. 小红书爬虫继续抓取笔记

## 配置项

| 配置 | 默认值 | 说明 |
|---|---|---|
| `_LOGIN_WAIT_TIMEOUT` | 180 秒 | 登录等待超时时间 |
| `_LOGIN_POLL_INTERVAL` | 3 秒 | 轮询间隔 |

## 已知限制

- 小红书登录页默认是二维码扫码，无需键鼠转发
- 如果登录页是短信验证码表单且无二维码入口，等待超时后返回空结果
- 截图是 JPEG 格式，quality=60，文件大小约 50-100KB

## 后续优化

- 支持短信验证码登录（需要键鼠转发或验证码中继）
